# Estructura del Proyecto DescuentoM

## Repositorios
- **dinocity**: Juego endless runner en Godot 4
- **controlab**: Gestión administrativa (JS + Supabase)

## App principal
- **Frontend**: FlutterFlow
- **Backend**: Supabase
- **Publicada**: App Store y Play Store

## Identidad visual
- Logo: diana verde con centro naranja
- Colores: verde (#22c55e), naranja (#f59e0b), azul marino (#0f172a)
- Tagline: "Caza cupones. Ahorra mejor."
